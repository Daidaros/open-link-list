# Open Link List

Chrome extension for opening a pasted list of URLs in separate tabs. Optionally, add them to a named tab group and choose its color.

The interface automatically follows Chrome's language setting. English and Spanish are currently included.

## Install locally

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked**.
4. Select this folder: `open-link-list`.
5. Optionally, pin the extension from Chrome's Extensions menu.

No data leaves the browser.
